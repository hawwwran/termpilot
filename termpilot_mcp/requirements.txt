# Runtime dependencies for termpilot_mcp.

#         `tp screenshot` and `tp tail -f` paths, and the read_screen MCP

#         Python) and worth the dep for the dramatic readability win on
#         TUI workers (Claude, vim, htop, lazygit, ...).
